Para cada archivo oficial seleccionado, el manifiesto versionado debe registrar:

- Proveedor (MINEDU/ESCALE) y título.
- URL de la página de origen y **URL exacta del archivo descargado**, incluidos parámetros necesarios no secretos.
- Nombre, formato, fecha real de publicación/corte y fecha de descarga.
- SHA-256 del contenido original.
- Columnas utilizadas, reglas de normalización, recuentos antes/después.
- Duplicados, discrepancias territoriales, revisión y aprobación.
